# Contador de Produtos v2

Novidades:
- Código escaneado/digitado que não existe no catálogo: exige nome do produto antes de adicionar.
- Produto sem código: exige nome e confirmação; no Excel, Código = NULL.
- Excel: Nome, Cadastro, Data e Hora aparecem apenas na primeira linha.
- Coluna `QTD Contabilizada` registra as unidades.
- Coluna `Quantidade de vezes que contou` registra quantas entradas foram feitas.

Publicação: envie `index.html`, `produtos.json` e `.nojekyll` para a raiz do repositório GitHub Pages.
